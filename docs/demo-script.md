# Five-Minute Demo Script

1. Introduce the problem: hybrid offices need a reliable way to manage shared desks.
2. Explain the database: departments, employees, floors, zones, seats, bookings, maintenance tickets and audit logs.
3. Open the Seats tab and show seat search plus available seats.
4. Open the Bookings tab and create a valid booking.
5. Try an overlapping booking to show validation.
6. Open Employees and Maintenance tabs to show operational records.
7. Open Reports and show occupancy, department booking totals and audit log.
8. End by explaining that the system uses JavaFX, JDBC and MySQL without ORM.
